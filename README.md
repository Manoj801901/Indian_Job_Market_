Indian Job Market Analysis Using Python

Project Overview

This project analyzes Indian job-market data to understand job demand, salary ranges, hiring locations, companies, experience levels, and required skills.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Excel

Project Activities

- Cleaned missing values and removed duplicate records.
- Analyzed job postings by title, location, and company.
- Compared salary ranges and experience requirements.
- Examined required skills and company ratings.
- Calculated key performance indicators (KPIs).
- Created charts to visualize job-market trends.

Key Findings

- Top job title: Application Developer
- Top location: Bengaluru
- Top company: Accenture

Conclusion

This project demonstrates practical skills in data cleaning, data analysis, KPI calculation, and data visualization using Python.
